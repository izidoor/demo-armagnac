Démonstration 2

Le contrat, conclu au chai

  1. Le vendeur saisit le contrat sur son téléphone, dans son stock estimé.
  2. L’acheteur est notifié, ajuste le prix.
  3. Le vendeur approuve : contrat conclu, PDF signé.
  4. La retiraison validée met à jour le stock et la DSM.

iPhone

  1. Ouvrir le lien dans Safari
  2. Toucher Partager
  3. Sur l’écran d’accueil

Android

  1. Ouvrir le lien dans Chrome
  2. Toucher le menu ⋮
  3. Ajouter à l’écran d’accueil
