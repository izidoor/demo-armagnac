# Patrons d'implémentation

Établis avec `referentiels`. Chaque patron cite son exemple ; le reprendre plutôt que réinventer.
Chemins relatifs à `backend/` ou `frontend/`.

## Structure

| Patron | Exemple |
|---|---|
| Un module Maven par contexte, couches en packages (ADR-010) : `bnia-<contexte>/pom.xml` (dépend de `bnia-commun`, starters web et JDBC), entrée dans `<modules>` du pom racine, dépendance dans `bnia-boot` | `bnia-referentiels/pom.xml` |
| Un schéma PostgreSQL par contexte, déclaré dans `spring.flyway.schemas` (créé par Flyway, pas par V1) | `bnia-boot/src/main/resources/application.yml` |
| Section du contexte dans la migration unique, dans l'ordre de `contextes.md` | `bnia-boot/src/main/resources/db/migration/V1__schema.sql` |
| Lire un autre contexte : seulement par sa partie publiée ou un port (ArchUnit) | `fr.bnia.referentiels.application.partage.ReferentielsLecture` |

## Domaine et application

| Patron | Exemple |
|---|---|
| Identifiant technique `Long`, `null` avant insertion, attribué par la base (`bigint generated by default as identity`) ; références entre contextes par identifiant avec clé étrangère (ADR-011) | `referentiels/domain/ValeurSimple.java` |
| Fabriques `creer(...)` (sans id) et `reconstituer(id, ...)` (depuis la persistance) | `referentiels/domain/Pays.java` |
| Objet-valeur qui valide et normalise à la construction, et lève `RegleEnfreinte(regle, message)` | `referentiels/domain/Code.java`, `Volume.java`, `CodeIso.java` |
| Exceptions métier communes : `RegleEnfreinte` (422), `ConflitUnicite` (409), `ElementUtilise` (409), `ElementIntrouvable` (404) | `bnia-commun/.../commun/domain/` |
| Agrégat qui garantit ses invariants et nomme l'élément en conflit dans le message | `referentiels/domain/ClasseTva.java` (RG-REF-11) |
| Plusieurs objets de même forme : une classe abstraite par couche, une sous-classe par objet (A-REF-3) | `ValeurSimple`, `GererValeursSimples`, `ValeursSimplesJdbc`, `ValeursSimplesController` |
| Cas d'usage : `@UseCase`, un seul constructeur public ; vérifie l'unicité à la création et à la modification (`existeCode(code, sauf)`) | `referentiels/application/GererValeurs.java` |
| Date du jour : `java.time.Clock` injectée (bean dans `bnia-boot`), horloge fixe en test | `GererClassesTva.java`, `boot/HorlogeConfiguration.java` |
| Port de lecture (listing) distinct du port d'écriture ; modèle de lecture en record (`…Ligne`) | `PaysLecture.java`, `PaysLigne.java` |
| Partie publiée : vues immuables (records) et interface à méthodes typées (par id, par code, actives) | `referentiels/domain/partage/`, `application/partage/` |

## Persistance

| Patron | Exemple |
|---|---|
| Ligne Spring Data JDBC en record imbriqué dans l'adapter, `@Table(schema = SCHEMA, …)`, mapping explicite `versLigne` / `versDomaine` | `adapter/persistence/PaysJdbc.java` |
| `JdbcAggregateTemplate.insert` (renvoie l'id) et `update` explicites | `adapter/persistence/ValeursJdbc.java` |
| Agrégat avec collection : `@MappedCollection(idColumn = …)`, enfants en `on delete cascade` | `adapter/persistence/ClasseTvaJdbc.java` |
| Suppression : `DataIntegrityViolationException` (clé étrangère) traduite en `ElementUtilise` | `ValeursJdbc.supprimer` |
| Listing : `Sql.where(filtre, colonnes…)` (actif, recherche `ilike` échappée), paramètre `null` typé (`Types.BIGINT`) | `adapter/persistence/Sql.java` |
| Unicité à la casse près : index unique sur `lower(code)` ; normalisation stockée si besoin (`libelle_normalise`) | `V1__schema.sql`, `MarqueJdbc.java` |

## REST et contrat

| Patron | Exemple |
|---|---|
| Ressources désignées par leur id (`/{id}`), `POST` → 201, `DELETE` → 204, actions en sous-ressources (`/{id}/desactivation`) | `adapter/rest/PaysController.java` |
| Même DTO de saisie pour la création et la modification (`Saisie…Request`) | `SaisiePaysRequest.java` |
| `operationId` explicite, ou `@Ressource(singulier, pluriel)` pour les opérations héritées | `ClasseTvaController.java`, `ZoneCommercialeController.java` |
| Erreurs en `ProblemDetail` avec la propriété `regle` | `bnia-commun/.../adapter/rest/GestionErreurs.java` |

## Tests

| Patron | Exemple |
|---|---|
| Test de domaine par RG : `rg_ref_11_…` + `@DisplayName("RG-REF-11 : …")`, cas limites en `@ParameterizedTest` | `referentiels/domain/ClasseTvaTest.java` |
| Repository en mémoire qui attribue les ids (`ValeursEnMemoire(avecId)`) | `bnia-referentiels/src/test/.../application/ValeursEnMemoire.java` |
| IT : `extends AbstractIT`, `client` et `creer(uri, corps)` renvoyant l'id ; codes uniques (UUID) ; IT paramétré quand plusieurs ressources ont le même contrat | `bnia-boot/src/test/.../referentiels/ListesSimplesIT.java` |
| Démo : `@Profile("demo")` `ApplicationRunner` qui passe par les cas d'usage, ignore `ConflitUnicite` (relançable), avec son IT | `bnia-boot/.../boot/demo/DemoReferentiels.java` |

## Front
